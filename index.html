🐾 레서판다의 움직임 연구소

블록을 누르고, 움직임을 관찰하고, 좌표를 찾아봐요!

움직임을 관찰해요

좌표판을 클릭하면 목표 X, Y가 자동 입력돼요. 파란 블록의 실행 버튼을 누르면 움직여요.

🎯 격자판을 눌러 목표 좌표를 고르세요. 아래 두 이동 블록에 같은 숫자가 들어가요.

위치 x: 0, y: 0방향: 90° →
먼저 오른쪽 블록 중 하나를 눌러 보세요.

블록 3종 비교

움직임 블록의 숫자를 바꾸고 직접 실행해 보세요.

① 왼쪽 격자판 클릭 → ② 자동 입력된 숫자 확인 → ③ 실행 ▶
숫자 칸을 직접 고쳐서 실행해도 돼요. 10만큼 움직이기는 좌표 선택과 관계없이 거리를 입력해요.

만큼 움직이기
x: y: (으)로 이동하기
초 동안 x: y: (으)로 이동하기

💡 두 좌표 이동 블록의 목표값을 똑같이 놓고 비교해 보세요. 한 블록은 즉시, 다른 블록은 시간을 들여 이동해요.

좌표 지도 탐험

격자판을 직접 클릭하거나 X, Y 숫자를 입력해 보세요. 가운데가 (0, 0)이에요.

현재 좌표 (0, 0)X → 오른쪽 / 왼쪽Y ↑ 위 / 아래
X X좌표는 좌우 이동
← 음수 −0+ 양수 →

0을 기준으로 왼쪽은 음수(−), 오른쪽은 양수(+)예요.

Y Y좌표는 위아래 이동
↓ 음수 −0+ 양수 ↑

0을 기준으로 아래는 음수(−), 위는 양수(+)예요.

좌표를 바꿔 봐요

X가 양수면 오른쪽, 음수면 왼쪽! Y가 양수면 위쪽, 음수면 아래쪽으로 이동해요.

🎯 좌표 찾기 도전

레서판다를 (100, 60) 위치로 보내 보세요! 격자판을 누를 때 작은 효과음이 들려요.

🎓 블록 선택 미션

설명을 읽고 가장 알맞은 블록을 골라 보세요.

🔎 X: 100, Y: 60은 블록의 숫자 칸에 들어가는 목표 좌표의 예시예요. 바로 이동하는지 1초 동안 이동하는지 살펴봐요.
